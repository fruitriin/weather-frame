# weather-frame

iPad をデジタルフォトフレームのように置いて、天気予報を表示し続けるための Web ページです。Split View の 1/3 幅（縦長）で 1 画面に収まるように作っています。

## 表示内容

- 現在の天気・気温・体感温度・湿度・風・降水確率
- 服装の目安（18時以降は明日の目安）
- 24時間の気温・体感温度・降水確率のグラフと天気アイコン（最初は 6 時間分を表示し、横スクロールで先を見る。1 分放置すると先頭に戻る）
- 雨雲（過去 2 時間の実況〜6 時間先の予報。ふだんは「今」のコマで止まっていて、地図か ▶ をタップすると 2 時間前から予報の終わりまでを 1 回再生する。シークバーでも移動できる）
- 風（アメダスの実況。観測点ごとの風向きの矢印と風速）。直近 2 時間〜6 時間先に雨がなく、降水確率も 30% 未満なら雨雲の代わりに表示する。見出しのタブで手動でも切り替えられ、1 分放置すると自動の判定に戻る
- 週間予報

予報は 15 分、雨雲は 5 分、風は 10 分ごとに自動で更新し、6 時間ごとにページを再読み込みします。

## URL パラメータ

| パラメータ | 内容 | 例 |
|-----|-----|-----|
| `lat` / `lon` | 地点の緯度・経度（省略すると東京駅） | `?lat=35.68&lon=139.76` |
| `name` | 画面に出す地点名 | `&name=自宅` |
| `zoom` | 雨雲の地図の倍率（既定は 9） | `&zoom=8` |
| `theme` | `light` で明るい配色 | `&theme=light` |

## データの出典

- 天気予報: [Open-Meteo](https://open-meteo.com/)
- 雨雲: 気象庁（高解像度降水ナウキャスト・降水短時間予報）。気象庁ホームページが内部で使っているタイルを読み込んでいるため、仕様が変わると表示されなくなる可能性がある
- 風: 気象庁（アメダス）。雨雲と同じく気象庁ホームページが内部で使っているデータを読み込んでいる
- 地図: [地理院タイル](https://maps.gsi.go.jp/development/ichiran.html)
